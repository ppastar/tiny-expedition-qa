### 실제 결함과 시연용의 차이

- **BUG-xxx = 실제로 이 프로젝트 코드에 있었던(또는 지금 있는) 결함**입니다. 재현은 해당 커밋을 받아 실제로 돌린 출력입니다.
- **DEMO-xxx = 시연용**입니다. [뮤테이션 스모크](../../scripts/mutation_smoke.py)가 쓰는 "그럴듯한 버그"를 코드에 **일부러** 넣고, 그 상태에서 재현 도구·테스트를 돌린 출력을 붙였습니다. "이런 결함이 들어오면 이렇게 리포트한다"를 보여 주기 위한 것이며, 실제 출시물에 있던 버그가 아닙니다.
- 출력은 모두 실제로 실행해 받은 것입니다. 게임 화면(Unity)에서 직접 해 보지 않은 절차는 "게임 화면 미실행"으로 표시했습니다.

## 양식

| 칸 | 쓰는 것 |
|---|---|
| 요약 | `[영역] 어떤 조건에서 → 무엇이 잘못됨`. 제목만 보고 무슨 문제인지 알 수 있게 |
| 환경 | 커밋(빌드), OS, 런타임/엔진 버전, 데이터 버전 |
| 심각도 | 결함이 사용자에게 주는 피해 (아래 기준) |
| 우선순위 | 고치는 순서. [테스트 계획](../TEST_PLAN.md)의 P0~P2 기준을 따름 |
| 사전조건 | 재현에 필요한 상태(보석, 천장 카운트, 데이터) |
| 재현 절차 | 번호를 붙여 한 줄에 동작 하나 |
| 기대 결과 / 실제 결과 | 숫자로. "이상함" 대신 "보석 3000 → 1500" |
| 재현율 | 시도 횟수 대비 재현 횟수 (예: 10/10). 시드·조건을 함께 |
| 첨부 | 시드, 리플레이 문자열, 로그, 테스트 실패 출력, 스크린샷 |
| 원인 / 수정 확인 | 원인이 된 코드, 수정 커밋, 회귀 TC와 그 결과 |

### 심각도 기준

| 심각도 | 기준 | 예 |
|---|---|---|
| Critical | 재화·확률·진행 데이터가 틀어짐, 크래시, 우회 불가 | 보석이 빠지고 결과 없음, 천장 미작동 |
| Major | 기능이 기획과 다르게 동작하지만 진행은 가능, 또는 특정 데이터에서만 기능이 막힘 | 판정 경계 오류, 특정 배너 10연 불가 |
| Minor | 표시·문구 오류, 쉽게 우회 가능 | 숫자 표기 오류 |
| Trivial | 사용자에게 거의 영향 없음 | 로그 문구 오탈자 |

심각도는 "얼마나 나쁜가", 우선순위는 "언제 고치나"입니다. 심각도가 높아도 발생 조건이 현재 데이터에 없으면 우선순위를 한 단계 낮출 수 있습니다 (BUG-002).
